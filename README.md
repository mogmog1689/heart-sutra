# 般若心経 暗唱マスター (Heart Sutra Master)

AndroidスマホやPCで手軽に般若心経を暗唱・学習できるPWA（Progressive Web App）です。

---

## 🌟 主な機能

1. **📿 フレーズ別 4択暗唱クイズ**
   - 直前の句を見て、「次に来る句」を4択から選んでテンポよく進める暗唱テスト。
   - 正解すると心地よい**木魚の打音（ポクッ）**とともに自動で次へ進みます。
   - 間違えた場合でも、ふりがな・現代語訳の丁寧な解説が表示され、確実に定着できます。
   - 全問クリアで清らかな**おりんの鐘の音（チーーン…）**が鳴り響きます。

2. **⛩️ 意味の区切り（章）ごとの学習**
   - 般若心経を意味のまとまりごとに5つの章に分類：
     - **第一章：序論**（観自在菩薩〜度一切苦厄）
     - **第二章：空の本質**（舎利子〜亦復如是）※色即是空
     - **第三章：諸法の実相**（是諸法空相〜以無所得故）※不生不滅・一切皆空
     - **第四章：菩薩の境地**（菩提薩埵〜得阿耨多羅三藐三菩提）※心無罣礙
     - **第五章：大呪と真言**（故知般若〜般若心経）※羯諦羯諦
   - 各章ごと、または「全編通し」の切り替えがワンタップで可能です。

3. **🔘 ワンタップ表示切り替え（上部バー）**
   - **🔔 音（入/切）**: 木魚やおりんの効果音のミュート切替。
   - **🈐 ルビ（入/切）**: 漢字の上のふりがな表示のON/OFF。
   - **💬 現代語訳（入/切）**: 句の下に表示される現代語訳のON/OFF。

4. **📖 暗唱カード送りモード**
   - スマホ画面いっぱいに1句ずつ大きく表示。
   - 自分のペースで左右にめくりながら読経できる自習モード。「ポクッ」と木魚を鳴らせる手動ボタン付き。

5. **📜 全文一覧モード**
   - 意味の区切りごとに整理された全53句をスクロール閲覧できる辞書的ビュー。

6. **📱 Android PWA（完全オフライン＆全画面）**
   - 外部ライブラリ依存ゼロ（Web Audio APIによる自作和楽器エンジン）。
   - ブラウザから「ホーム画面に追加」するだけで、ネイティブアプリ同様に全画面・オフラインで動作します。

---

## 🚀 使い方・確認手順

### 方法1: PCのブラウザで直接開く（最も簡単）
フォルダ内の `index.html` をダブルクリック（またはブラウザにドラッグ＆ドロップ）するだけで、今すぐ動作確認できます。

### 方法2: スマホ（Android）から開いてアプリ化する
同じWi-Fiに接続している状態で、PowerShellから簡易サーバーを起動します：

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

1. 画面に表示される `http://192.168.x.x:8080` をスマホの Chrome で開きます。
2. 右上のメニュー（︙）をタップし、**「ホーム画面に追加」**（または「アプリをインストール」）を選択します。
3. スマホのホーム画面にアプリアイコンが追加され、オフラインでも全画面アプリとして使えます！
